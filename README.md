## About:
This is my weekend project that I built for the sake of having an aesthetic dashboard to monitor my system.
## Attributes:
- Translucent dashboard background.
- Automatic color scheme adjustment according to Omarchy theme.
## Note:
- This is a sci-fi themed dynamic dashboard specifically created for ASUS Laptops.
  - This is due to metrics on dashboard that are specific to ASUS laptops.
  - Specific metrics use tools like asusctl and supergfxctl, that are specific to ASUS laptops.
- I built it for my hyprland managed desktop on Omarchy OS.
- This repository consists of only the qml and manifest files.
- The configuration script would be released in due time.
## Caution:
- Significant power consumption due to about 25 processes spawned every second.
- Advised to avoid use on battery power.
